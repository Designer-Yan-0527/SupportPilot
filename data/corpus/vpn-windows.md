# Windows 电脑连接公司 VPN 配置指南

> 文档编号 KB-1003 | 适用系统 Windows 10 / 11 | 维护人 IT Service Desk

## 1. 适用范围

本指南适用于使用公司配发 Windows 台式机或笔记本的员工。需要访问内网 Git、Jira、财务系统的同事，必须先通过 VPN 接入。个人电脑接入前请先提交「设备合规申请」。

## 2. 前置条件

- 已完成入职工单，并拿到公司邮箱账号。
- 已启用多因素认证（MFA），手机可正常接收推送。
- 设备已加入公司域，右下角能看到「域连接正常」提示。
- 系统已激活，且 Windows Update 未被手动关闭，否则证书链校验会失败。

## 3. 下载并安装客户端

1. 打开内网门户 https://portal.example.com，使用公司邮箱登录。
2. 进入「软件中心 > 网络工具」，下载 Windows 版 VPN 客户端。
3. 右键安装包，选择「以管理员身份运行」。
4. 安装过程中若弹出「设备软件警告」，点击「仍要安装」。
5. 安装完成后重启电脑，确保虚拟网卡驱动生效。

## 4. 导入证书并建立连接

1. 在门户的「证书管理」页面下载个人证书，文件名通常为 `vpn-<工号>.p12`。
2. 双击证书文件，选择「本地计算机」存储位置，密码输入证书密码。该密码与门户登录密码不同，首次下载时页面只显示一次，请立即保存。
3. 打开 VPN 客户端，选择配置文件「Corp-Remote」，点击「连接」。
4. 在弹出的 MFA 提示中核对数字是否一致，确认后点击「批准」。

## 5. 常见错误码

| 错误码 | 含义 | 处理方式 |
| --- | --- | --- |
| E-502 | 虚拟网卡启动失败 | 打开「服务」，启动 IKE and AuthIP IPsec 服务后重试 |
| E-509 | 证书已过期 | 到门户重新下载证书，并删除本地证书存储中的旧证书 |
| E-511 | 域凭据失效 | 锁屏后用新密码重新登录域账号，再发起连接 |
| E-512 | 代理冲突 | 关闭第三方代理软件，或在客户端中改为「直连」 |

## 6. 卸载与重装

若客户端反复崩溃，先在「设置 > 应用」中卸载，再删除 `C:\Program Files\CorpVPN` 目录，最后重新按第 3 节安装。卸载前请记录当前证书的到期时间，避免重装后无法连接。

## 7. 仍然无法解决

请携带设备编号与错误码截图提交工单，分类选择「网络与 VPN」。工作时间内通常在 2 小时内首次响应，紧急故障请直接拨打服务台电话。
